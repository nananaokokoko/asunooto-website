# アスノオト コーポレートサイト

株式会社アスノオトのコーポレートサイトです。Next.js + TypeScript + Tailwind CSSで構築され、NotionをCMSとして利用しています。

## 特徴

- 📝 **Notion連携**: メンバー情報とニュースをNotionで管理
- 🎨 **モダンなデザイン**: 現在のサイトデザインを踏襲しつつ改善
- 📱 **レスポンシブ対応**: PC・タブレット・スマホに最適化
- ⚡ **高速**: 静的サイト生成（SSG）により高速表示
- 🔄 **自動更新**: ISR（Incremental Static Regeneration）で定期的に更新

## セットアップ手順

### 1. Notionの準備

#### 1-1. Notionインテグレーションの作成
1. [https://www.notion.so/my-integrations](https://www.notion.so/my-integrations) にアクセス
2. 「新しいインテグレーション」をクリック
3. 名前を入力（例：アスノオトWebサイト）
4. ワークスペースを選択
5. 作成後、「Internal Integration Token」をコピー

#### 1-2. メンバー用データベースの作成
Notionで新しいデータベースを作成し、以下のプロパティを設定：

| プロパティ名 | タイプ | 説明 |
|------------|--------|------|
| 名前 | タイトル | メンバーの名前 |
| 肩書き | テキスト | 例：代表取締役／さとのば大学 理事長 |
| 役職 | セレクト | 例：代表取締役、取締役、監査役 |
| 説明 | テキスト | プロフィール文章 |
| 順序 | 数値 | 表示順（小さい順） |

#### 1-3. ニュース用データベースの作成
Notionで新しいデータベースを作成し、以下のプロパティを設定：

| プロパティ名 | タイプ | 説明 |
|------------|--------|------|
| タイトル | タイトル | ニュースのタイトル |
| 日付 | 日付 | 公開日 |
| 内容 | テキスト | ニュースの本文 |
| カテゴリ | セレクト | お知らせ、組織、イベント、メディア等 |
| URL | URL | 外部リンク（オプション） |

#### 1-4. データベースの共有設定
1. 各データベースの右上「共有」ボタンをクリック
2. 作成したインテグレーションを招待
3. データベースのURLから`DATABASE_ID`を取得
   - URL例: `https://www.notion.so/xxxxx?v=yyyy`
   - `xxxxx`の部分がDATABASE_ID

### 2. プロジェクトのセットアップ

```bash
# 1. 依存関係のインストール
npm install

# 2. 環境変数の設定
cp .env.local.example .env.local

# 3. .env.localファイルを編集
# NOTION_API_KEY=取得したAPIキー
# NOTION_MEMBERS_DATABASE_ID=メンバーDBのID
# NOTION_NEWS_DATABASE_ID=ニュースDBのID

# 4. 開発サーバーの起動
npm run dev
```

### 3. デプロイ

#### Vercelでのデプロイ（推奨・無料）

1. [Vercel](https://vercel.com)にサインアップ
2. GitHubにプロジェクトをプッシュ
3. Vercelで「New Project」→ GitHubリポジトリを選択
4. 環境変数を設定（.env.localと同じ内容）
5. デプロイ

#### その他のホスティング

```bash
# 静的ファイルの生成
npm run build

# outフォルダの中身をサーバーにアップロード
```

## 運用方法

### メンバー情報の更新
1. Notionのメンバーデータベースで情報を編集
2. 1時間以内に自動で反映（すぐ反映したい場合はVercelで再デプロイ）

### ニュースの追加
1. Notionのニュースデータベースに新規ページを作成
2. 必要な情報を入力
3. 1時間以内に自動で反映

### デザインのカスタマイズ
- `tailwind.config.js`: カラーやフォントの設定
- `styles/globals.css`: グローバルスタイル
- `components/`: 各コンポーネントのデザイン

## よくある質問

### Q: Notionを使わずに運用できますか？
A: はい、`lib/notion.ts`のダミーデータを編集することで、Notion無しでも運用可能です。

### Q: 月額費用はかかりますか？
A: 基本的に無料です。
- Vercel: 無料プラン内で十分
- Notion: 無料プランでOK（有料プランならより多機能）

### Q: 更新頻度を変更できますか？
A: `pages/index.tsx`の`revalidate`値を変更してください（秒単位）。

## サポート

問題が発生した場合は、以下をご確認ください：
1. 環境変数が正しく設定されているか
2. NotionのAPIキーとデータベースIDが正しいか
3. Notionデータベースにインテグレーションがアクセス権を持っているか
