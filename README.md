# 株式会社アスノオト 公式サイト

- 内容（メンバー・お知らせ・沿革・会社概要・代表メッセージ・共創オーナー・その他のご支援のかたち）は、Notion の「アスノオト公式サイト 更新用」ページで編集します。Notion を直すと、約1分後からサイトに反映されます。
- Notion につながっていないときは、`content/site.json` に入っている控えの内容が表示されます。
- Notion とつなぐには、Vercel の環境変数 `NOTION_TOKEN` に Notion の接続キーを入れます。
- 見た目は `styles/globals.css`、トップページの構成は `pages/index.tsx` にあります。
- 旧サイトのお知らせURL（`/news/2025/08/post-22.html` など）は、新しいURLへ自動で転送されます。
